# 신규 셀러 지원 운영 의사결정안

이 문서는 공개 채용공고와 셀러 가이드를 바탕으로 만든 제안입니다. 실제 배민의 현재 운영 절차가 아닙니다.

## 매일 기록할 항목

- 셀러 ID와 담당자
- 신청일, 현재 단계, 마지막 처리일
- 보완 요청 횟수와 미해결 항목
- 문의 유형과 같은 문제의 재문의 여부
- 오픈 예정일과 다음 행동
- 계약, 정산, 상품 정보 오류 여부

## 우선 대응 판단

1. 법적, 정산, 계약 정보 오류처럼 정확성 검토가 먼저 필요한 건을 분리합니다.
2. 장기 대기와 반복 문의가 함께 발생한 셀러를 먼저 확인합니다.
3. 판매 준비가 임박한 건에는 하루 처리 여력의 일부만 배정합니다.
4. 기준 시간을 넘긴 셀러가 목록에서 빠지지 않도록 최장 대기를 확인합니다.
5. 담당자가 없는 건과 다음 행동이 비어 있는 건은 당일 배정합니다.

기준 시간과 처리 여력은 가상 수치로 고정하지 않고 실제 팀의 단계 정의와 업무량을 확인한 뒤 정합니다.

## 주간 개선 회의

- 재문의율과 보완 반복률이 높은 문제를 고릅니다.
- 개별 셀러 문제인지 여러 셀러에게 반복되는 구조적 문제인지 구분합니다.
- 안내 문구, 셀러 체크리스트, 내부 인계 절차 중 바꿀 대상을 한 개 정합니다.
- 다음 주에 재문의, 대기, 정보 오류, 담당자 추가 업무시간이 어떻게 변했는지 확인합니다.

## 2주 시험 운영

- **1~2일:** 팀에서 쓰는 용어와 완료 기준을 맞추고 기존 사례 20건을 입력합니다.
- **3~7일:** 매일 10분 동안 먼저 볼 일을 정하고, 분류가 맞는지와 기록 시간을 확인합니다.
- **8~12일:** 반복 문의 한 가지의 안내문을 바꾸고 같은 문의와 재문의가 줄었는지 봅니다.
- **13~14일:** 담당자와 협업 부서의 의견을 듣고 유지, 수정 또는 중단을 결정합니다.
- **계속 사용할 조건:** 재문의와 장기 대기가 줄고, 정보 오류, 담당자 부담, 특정 셀러 방치가 악화되지 않아야 합니다.

## 아직 확인할 수 없는 것

실제 병목 단계, 내부 시스템, 담당자 처리 여력, 재문의 원인과 정책 효과는 공개 자료와 가상 데이터만으로 알 수 없습니다. 실제 데이터와 담당자 인터뷰를 통해 다시 정의해야 합니다.
