# 신규 셀러 온보딩 안내 초안

## 신청 직후

- 현재 단계: 신청 접수
- 다음 단계: 서류 확인
- 준비 자료: 사업자 정보, 정산 정보, 판매 예정 상품 목록
- 완료 기준: 필수 항목이 모두 입력되고 담당자가 검토를 시작한 상태

## 보완 요청을 받았을 때

1. 누락된 항목과 수정 이유를 확인합니다.
2. 안내된 예시와 형식을 기준으로 수정합니다.
3. 원래 제출한 위치에서 다시 제출합니다.
4. 제출 뒤 상태가 ‘재검토 중’으로 바뀌었는지 확인합니다.

## 상품 등록 전에

- 상품명, 카테고리, 가격, 이미지 규격을 확인합니다.
- 등록 예정 상품이 많으면 우선 판매할 상품부터 나눠 등록합니다.
- 같은 오류가 반복되면 오류 문구와 상품 번호를 함께 전달합니다.

이 안내는 가상 프로젝트용 초안입니다. 실제 회사의 정책, 필수 서류, 시스템 화면에 맞게 검토해야 합니다.
