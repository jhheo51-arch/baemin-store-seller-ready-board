# 셀러 레디 보드

배민스토어 운영지원 채용공고를 읽고 직접 만든 셀러 온보딩 운영안입니다.

처음에는 셀러의 요청을 빨리 처리하는 일이 가장 중요하다고 생각했습니다. 공식 가이드를 읽으며 상품 노출, 주문 접수, 배달, 정산이 이어져야 판매 준비가 끝난다는 점을 알게 됐습니다. 그래서 접수 순서만 보는 목록 대신, **오래 기다린 건·정보 오류·오픈 임박·담당자 미배정**을 나눠 보고 다음 행동과 완료 기준까지 남기는 보드를 만들었습니다.

![셀러 레디 보드 프로젝트 화면](assets/project-overview.png)

## 1. 문제 정의

신규 셀러 요청이 한꺼번에 들어오면 접수 순서만으로는 정보 오류, 오래 기다린 건, 오픈 임박, 담당자 미배정을 구분하기 어렵습니다. 온보딩 완료를 단순 등록이 아니라 **실제로 주문을 받을 준비가 된 상태**로 다시 정의했습니다.

## 2. 자료와 가정

채용공고와 배민스토어 공식 운영 가이드를 문제 정의에 사용했습니다. 셀러 12건과 문의·단계·업무 기록은 판단 구조를 시험하기 위한 가상 자료이며, 실제 셀러 정보나 내부 운영 기준을 사용하지 않았습니다.

## 3. 지표 분석

공식 자료의 2024년 3~4월 주문 취소 사유 중 `재고 소진 29.6%`, `주문 접수 미인지 19.2%`를 보고 속도만큼 정보 정확성과 주문 준비 상태가 중요하다고 판단했습니다. 운영 시험에서는 3일 내 처리율, 7일 내 재문의율, 장기 대기, 정보 오류율, 담당자 기록시간을 함께 봅니다.

## 4. 내가 한 판단

우선순위를 `정보 오류 → 장기 대기·재문의 → 오픈 임박 → 담당자 미배정` 순서로 나눴습니다. 빠르게 닫은 업무 수만 늘리는 대신, 왜 먼저 봐야 하는지와 다음 행동·담당자·완료 근거가 함께 남도록 설계했습니다.

## 5. 작동 화면

웹 화면과 Excel에서 셀러를 선택하면 위험 신호, 판단 근거, 다음 행동과 완료 기준을 확인할 수 있습니다. 대기일·재문의·오픈일·담당자를 바꾸면 우선 신호가 다시 계산됩니다.

## 6. 검증 결과

가상 원본 자료와 Excel 계산식, PDF 핵심 수치가 연결되는지 확인했습니다. 2주 시험 절차와 일일 운영·다른 부서 인계 기준도 문서화했지만, 실제 팀에서 처리시간이나 재문의가 줄었다는 결과는 아닙니다.

## 7. 아직 확인하지 못한 것

- 실제 팀의 단계별 처리 기준과 담당자별 업무량
- 우선 신호가 기존 방식보다 장기 대기와 재문의를 줄이는지
- 기록 시간이 늘어나는 부담보다 누락 방지 효과가 큰지
- 셀러와 유관 부서가 이해하기 쉬운 안내 문구인지

## 세 자료가 연결되는 방식

1. **PDF에서 문제와 판단을 설명합니다.** 공식 자료를 읽고 왜 네 가지 신호를 골랐는지, 대표 사례를 어떤 순서로 처리할지 보여줍니다.
2. **Excel에서 같은 판단을 작동시킵니다.** PDF에 나온 가상 셀러와 네 가지 신호를 사용하며, 대기일·재문의·오픈일·담당자를 바꾸면 먼저 볼 신호가 다시 계산됩니다.
3. **GitHub에서 근거와 과정을 확인할 수 있습니다.** Excel에 사용한 가상 원본 자료, 항목의 뜻, 일일 운영 방식과 계산 과정을 함께 남겼습니다.

세 자료는 `공식 자료에서 문제 발견 → 우선 판단 기준 설정 → 가상 사례에 적용 → Excel로 작동 확인 → 2주 시험 제안`의 한 흐름으로 이어집니다.

## 공식 자료에서 찾은 문제

배민스토어 공식 노하우에는 2024년 3~4월 주문 취소 사유로 재고 소진 29.6%, 주문 접수 미인지 19.2%가 소개되어 있습니다. 이 내용을 보고 오픈 여부만 확인하는 것으로는 부족하다고 생각했습니다. 판매 전 재고 일치, 판매 중지 상품, 주문 알림 상태까지 확인하는 가상 사례를 만들었습니다.

## 제가 보여드리고 싶은 점

공고에 나온 역량을 그대로 옮기기보다, 실제로 맡게 될 일을 구체적으로 상상했습니다. 무엇을 먼저 볼지, 셀러에게 어떻게 설명할지, 다른 부서에는 무엇을 물을지, 일이 끝났다고 보는 기준까지 직접 정했습니다.

이 프로젝트의 셀러와 운영 수치는 가상입니다. 실제 팀에 적용한다면 기존 사례로 분류 기준을 먼저 맞추고, 2주 동안 효과와 기록 부담을 함께 확인하겠습니다.
